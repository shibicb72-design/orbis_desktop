# PR 4: mozconfig and branding skeleton

Branch `pr4-branding`, off `main`. Plan: `orbis-desktop-phase0.md`, sections C.2 and D (PR 4). No build was run
(not possible yet) and nothing was installed.

## What

- `mozconfig`: Windows x64 release build. `--with-branding=browser/branding/orbis`, `--disable-official-branding`,
  `--with-app-name=orbis`, `--enable-update-channel=release`, `--enable-release`, `--enable-optimize`,
  `--disable-debug`; no updater, update agent, maintenance service, crash reporter or default-browser agent;
  `MOZ_TELEMETRY_REPORTING=` (off); `MOZ_REQUIRE_SIGNING=1` (add-on signing stays enforced; it is already the
  default for release milestones, set explicitly so it cannot change silently). Build output goes to
  `..\obj-orbis`, next to the checkout and outside this repository.
- `overlay/browser/branding/orbis/`: started from Firefox 160's `browser/branding/unofficial`. Names set to
  "Orbis" in `configure.sh`, `brand.ftl`, `brand.properties` and `branding.nsi`; `trademarkInfo` carries the
  attribution; the template's updater prefs and `devtools.selfxss.count` are dropped.
  **All artwork is a new TODO placeholder** (blue disc, white "O", "TODO"). No Firefox or Mozilla art.
- `scripts/make-placeholder-branding.ps1`: draws the 40 placeholder PNG/ICO/BMP/JPG files at the template's file
  names and sizes. The four SVGs were written by hand.
- `scripts/apply-overlay.ps1`: copies the branding, `mozconfig` and (when present) the PR 3 policy files into the
  checkout. Refuses any path outside it.
- `scripts/check-mozconfig.py` (run with `python -I`): checks every mozconfig option against the pinned source.
- `docs/BRANDING.md`: trademark rules, how the build picks up the branding, why no template art is used, open
  items. `AGENTS.md` and `README.md`: project map and commands.

## Licence check of the template art

Not reused. The template's images carry no licence notice; `about-logo.svg` (the blue globe) has no MPL header;
`firefox-wordmark.svg` and `about-wordmark.svg` draw the word "Firefox"; the source's `LICENSE` says "You are not
granted rights or licenses to the trademarks of the Mozilla Foundation or any party, including without limitation
the Firefox name or logo." I found nothing that allows reuse, so only file names and pixel sizes were taken.
MPL-licensed text files (build files, CSS, XML, NSIS defines) were copied and edited, with their MPL headers.

## Trademark rules (docs/BRANDING.md)

- No "Firefox" or "Mozilla" in the product name, icons or UI text; the name is "Orbis" and the binary `orbis.exe`.
- Truthful attribution is kept: "Orbis is based on Mozilla's Firefox source code and is not made or endorsed by
  Mozilla. Firefox and Mozilla are trademarks of the Mozilla Foundation."
- The user agent still says `Firefox/160.0`. The token comes from `MOZ_APP_BASENAME` ("Firefox") in
  `nsHttpHandler.cpp`; changing it would make Orbis users stand out and break sites, so it is left alone.
