## LICENSE check against the Firefox source tag

At `FIREFOX_160_0_RELEASE` (`2887d9de1f69c0e9776413da80e7ba0d1225dd9b`) the root `LICENSE` is **not** the MPL
text. It is a 9-line pointer to `toolkit/content/license.html` plus a trademark notice. So the comparison was made
against the MPL copies that the tag does carry:

- `toolkit/content/licenses/mpl.html` (the MPL shown in `about:license`): after removing HTML tags and collapsing
  whitespace, the wording is word-for-word identical to the mozilla.org text. The only differences are formatting
  of the plain-text file: 11 list labels such as `(a)` (generated by HTML `<ol>`) and 2 dash underlines. Both use
  `https://mozilla.org/MPL/2.0/` in Exhibit A.
- `third_party/rust/glean-core/LICENSE` (plain text): identical except Exhibit A says `http://` instead of
  `https://` (one character).
- `%USERPROFILE%\work-orbis\LICENSE` is identical to the mozilla.org file after CRLF to LF conversion.
