Orbis Browser for Windows: Privacy Policy

Effective date: November 12, 2026. App: Orbis Browser for Windows, from the Microsoft Store (Store ID 9N9C8WTZRJ3P).

Summary

Orbis Browser is a web browser for Windows. It is based on Mozilla's Firefox source code and is not made or endorsed by Mozilla. The developer of Orbis receives no data about you or your browsing.

  • There is no account, sign-in or sync.
  • There is no telemetry, no analytics, no studies and no crash reporting.
  • There are no Orbis servers. Orbis sends nothing to the developer.
  • Your browsing data stays on your PC.

What stays on your PC

Your browsing data, such as history, bookmarks, cookies, saved passwords and settings, is stored only in your Orbis profile on your PC. Orbis has no account or sync, so it does not copy this data anywhere. The developer holds no copy.

Private browsing

In private windows, what you type in the address bar is not sent for search suggestions. HTTPS-only mode, tracking protection and the isolation of third-party cookies per site also apply in private windows, and uBlock Origin, if you installed it, works in them too.

First run: uBlock Origin

When you start Orbis for the first time, one screen offers the uBlock Origin content blocker, with the box "Install uBlock Origin ad blocker" checked. uBlock Origin is a separate project (GPL-3.0). It is not made or endorsed by Orbis or Mozilla, and it is not included in Orbis.

  • If you click Continue with the box checked and accept the browser's "Add uBlock Origin?" prompt, Orbis downloads uBlock Origin from addons.mozilla.org.
  • If you uncheck the box, nothing is downloaded or installed.
  • If you close the screen without an answer, or uBlock Origin is not installed (for example, you cancel the prompt), the screen is shown again at the next start. It is not shown again after you decline or after uBlock Origin is installed.

What leaves your PC, and when

Orbis contacts the services below. Each of them sees your IP address and the request it receives. Their own privacy policies apply.

  • Websites you visit receive what any browser sends them, such as your IP address, the page request and the cookies they set. Orbis starts with Enhanced Tracking Protection set to Strict and with HTTPS-only mode on. You can change both.
  • Search goes to the search engine you choose. DuckDuckGo is the default.
  • Search suggestions (on by default, never in private windows; you can turn them off): with DuckDuckGo, what you type in the address bar is sent to duckduckgo.com as you type.
  • Mozilla Remote Settings (firefox.settings.services.mozilla.com, with files from firefox-settings-attachments.cdn.mozilla.net and the signing certificate from content-signature-2.cdn.mozilla.net): at start and when new data is announced. It delivers security data, such as certificate revocation lists, the add-on blocklist and tracking-protection lists. Orbis checks the signature of this data before it uses it.
  • Mozilla's push service (push.services.mozilla.com): a connection opened at every start and kept open. It tells Orbis at once when new security data is available, and it delivers notifications from websites that you allow to send them. The connection carries an ID for your Orbis profile, which lets Mozilla's push server recognise the same profile across starts.
  • Media plugins (aus5.mozilla.org): about once a day, Orbis downloads Mozilla's list of media plugins. The OpenH264 video codec, which video calls on the web (WebRTC) need, is downloaded from Cisco (ciscobinary.openh264.org) once and when it is updated. The Widevine DRM plugin is downloaded only if you turn DRM on; it is off by default.
  • addons.mozilla.org: only if you accept uBlock Origin on the first-run screen, or install an add-on later. Orbis then downloads the add-on there and checks versioncheck-bg.addons.mozilla.org for its updates about once a day.
  • uBlock Origin's filter lists (only with uBlock Origin installed): uBlock Origin itself downloads its filter lists right after the install and then on its own update schedule, from their publishers and mirrors: ublockorigin.github.io, ublockorigin.pages.dev, cdn.jsdelivr.net, raw.githubusercontent.com, secure.fanboy.co.nz, malware-filter.gitlab.io, curbengh.github.io, phishing-filter.pages.dev and pgl.yoyo.org, and the public suffix list from publicsuffix.org. Orbis chooses which lists are on.
  • Certificate authorities (OCSP): when a website's certificate needs a revocation check that the lists on your PC cannot answer, Orbis asks the authority that issued it. This tells that authority which website's certificate is checked.
  • Page translation runs on your PC. When you translate a page into a new language pair, the language model is downloaded once from Mozilla.
  • Location: only when a website asks and you allow it. Orbis then uses the Windows location service, not Google's.
  • Updates come only from the Microsoft Store. Orbis has no updater of its own.

No Google Safe Browsing

Orbis does not use Google Safe Browsing, so it does not send website or download information to Google for phishing and malware checks. Protection against phishing and malware sites comes from uBlock Origin's filter lists. If you do not install uBlock Origin, Orbis has no phishing or malware site protection. The first-run screen says this before you decline.

Turned off

Orbis turns off Firefox's telemetry, studies and experiments, crash reports, Mozilla accounts and sync, sponsored content and recommendations, the location lookup that guesses your country, Mozilla's DNS over HTTPS rollout, and the AI chatbot. The connectivity and Wi-Fi login page checks are off by default; you can turn them on.
